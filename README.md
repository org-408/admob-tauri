# admob-tauri

A [Tauri 2](https://tauri.app) plugin for [Google AdMob](https://admob.google.com) on iOS and Android: a port of
[`@capacitor-community/admob`](https://github.com/capacitor-community/admob) that keeps its API (same method names,
arguments, results and events), so an app moving from Capacitor to Tauri Mobile only changes an import.

Banner, interstitial and rewarded ads, plus the Google UMP consent flow (including the privacy options form) and iOS
App Tracking Transparency.

Status: **in development, not published yet.** The first release targets `@capacitor-community/admob` 8.3.0.

This is an independent community project. It is not affiliated with or endorsed by Google, the Tauri Programme or the
Capacitor Community. It is not an official Tauri plugin.
