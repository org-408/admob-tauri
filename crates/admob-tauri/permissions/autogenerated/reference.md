## Default Permission

Allows every command of the AdMob plugin

#### This default permission set includes the following:

- `allow-initialize`
- `allow-tracking-authorization-status`
- `allow-request-consent-info`
- `allow-show-privacy-options-form`
- `allow-request-tracking-authorization`
- `allow-show-consent-form`
- `allow-reset-consent-info`
- `allow-set-application-muted`
- `allow-set-application-volume`
- `allow-show-banner`
- `allow-resume-banner`
- `allow-hide-banner`
- `allow-remove-banner`
- `allow-start-native-ad-feed`
- `allow-destroy-native-ad-feed`
- `allow-load-native-ad`
- `allow-update-native-ad-placements`
- `allow-remove-native-ad`
- `allow-capture-native-ad-snapshot`
- `allow-prepare-native-ad-snapshot`
- `allow-prepare-interstitial`
- `allow-show-interstitial`
- `allow-prepare-reward-video-ad`
- `allow-show-reward-video-ad`
- `allow-prepare-reward-interstitial-ad`
- `allow-show-reward-interstitial-ad`
- `allow-load-app-open`
- `allow-show-app-open`
- `allow-is-app-open-loaded`
- `allow-register-listener`
- `allow-remove-listener`
